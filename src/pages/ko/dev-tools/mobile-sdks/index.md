Metaplex 모바일 SDK는 Android와 iOS에서 Metaplex 프로그램의 NFT 데이터를 읽기 위한 커뮤니티 라이브러리입니다. 두 SDK 모두 지원이 중단되어 더 이상 유지 관리되지 않습니다. {% .lead %}

## 사용 가능한 SDK

Token Metadata, Auction House, Candy Machine 계정의 읽기 작업을 지원하는 두 가지 플랫폼 SDK가 공개되었습니다:

- [Android SDK](/dev-tools/mobile-sdks/android) — Android 애플리케이션용 Kotlin 라이브러리
- [iOS SDK](/dev-tools/mobile-sdks/ios) — iOS 애플리케이션용 Swift 라이브러리

## 참고사항

- 두 SDK 모두 지원이 중단되었습니다. [Core](/smart-contracts/core) 이전에 만들어져 레거시 Token Metadata 데이터만 읽을 수 있습니다
- 현재의 모바일·클라이언트 개발에는 [UMI](/dev-tools/umi) JavaScript 프레임워크를 사용하거나 [DAS API](/dev-tools/das-api)를 HTTP로 직접 쿼리하세요
