# Cusper

Cusper 从 Solana 程序日志或错误代码解析**自定义程序错误**。它被 [Solita](/zh/dev-tools/solita) 用于使处理程序错误变得更加容易。

- [API 文档](https://metaplex-foundation.github.io/cusper/docs/)
